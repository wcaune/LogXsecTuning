## Use `submit_nova_art.py`

- running python /path/to/submit_nova_art.py will execute whichever version of python is in your $PATH, and use it to run the script
- running submit_nova_art.py will directly execute the version of that script that's in your $PATH
- running /path/to/submit_nova_art.py will execute that version of the script directly
- side note: if you have a copy of submit_nova_art.py in your current directory, just running submit_nova_art.py will still execute the version of the script that's in your $PATH. to run the local version, you need to provide the relative path like ./submit_nova_art.py
